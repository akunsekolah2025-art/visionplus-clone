# visionplus-clone

Vision+ Clone adalah proyek website streaming TV yang dibuat menggunakan HTML, CSS, dan JavaScript. Website ini memiliki tampilan modern dan responsif yang memungkinkan pengguna menjelajahi berbagai kanal televisi Indonesia melalui tautan streaming resmi atau halaman tontonan masing-masing kanal.

✨ Fitur

Daftar Kanal TV: Menampilkan 12 kanal TV beserta logo dan tautan tontonan.

Pencarian Kanal: Memudahkan pengguna menemukan kanal berdasarkan nama.

Kanal Favorit: Menyimpan kanal favorit agar lebih mudah diakses kembali.

Dark Mode & Light Mode: Pilihan tema tampilan yang dapat disimpan.

Banner Carousel: Menampilkan banner unggulan yang berganti secara otomatis.

Desain Responsif: Tampilan menyesuaikan ukuran layar desktop, tablet, dan smartphone.

Fullscreen: Mendukung mode layar penuh melalui browser yang kompatibel.

Progressive Web App (PWA): Mendukung instalasi sebagai aplikasi melalui browser yang kompatibel.

Penyimpanan Lokal: Menggunakan penyimpanan browser untuk fitur seperti tema dan favorit.

🚀 Cara Menjalankan

Menjalankan secara lokal

Unduh atau clone repository ini.

Pastikan file HTML, manifest, service worker, dan ikon aplikasi berada pada lokasi yang sesuai.

Jalankan website melalui server lokal seperti VS Code Live Server.

Buka alamat lokal yang ditampilkan oleh server di browser.

Deploy ke Netlify

Unggah seluruh file proyek ke repository GitHub.

Login ke Netlify.

Pilih Add new project dan impor repository GitHub.

Untuk proyek HTML statis, kosongkan Build command dan atur Publish directory ke . jika file utama berada di root repository.

Jalankan deploy dan tunggu hingga selesai.

Buka URL HTTPS yang diberikan Netlify.

Setelah website online, perubahan pada repository dapat diterbitkan kembali melalui proses deploy otomatis jika integrasi GitHub telah diaktifkan.

📱 Instalasi PWA

Website dapat dipasang sebagai aplikasi apabila konfigurasi PWA telah benar dan browser mendukung instalasi.

Android: Buka website melalui browser yang kompatibel, lalu pilih opsi instalasi atau tambahkan ke layar utama.

Desktop: Gunakan opsi instalasi yang tersedia pada browser.

iOS: Buka website melalui Safari, pilih menu Bagikan, lalu pilih Tambahkan ke Layar Utama.

Service Worker dapat membantu menyimpan aset website untuk meningkatkan pengalaman penggunaan. Namun, tayangan streaming eksternal tetap memerlukan koneksi internet dan bergantung pada ketersediaan layanan terkait.

⚠️ Catatan

Proyek ini dibuat untuk keperluan pembelajaran dan simulasi pengembangan antarmuka streaming TV. Website ini bukan aplikasi resmi Vision+ dan tidak berafiliasi dengan pemilik merek Vision+.

Ketersediaan kanal, logo, dan tautan streaming bergantung pada situs penyedia masing-masing. Hak atas merek dagang, logo, dan konten tetap dimiliki oleh pemiliknya.
